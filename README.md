# Suppliers — Shared Directory

> One repo. All suppliers. Every store references this.

## Why

Figg Studio, OddHobbies, DivergentJoy, Grimoirer, and PogPet all need the same suppliers. Instead of duplicating supplier info in each repo, we keep one canonical source here.

## Stores

| Store | Products | Primary Supplier |
|-------|----------|------------------|
| **Figg Studio** (pog.pet) | Custom pet figures, cards, ornaments | Makr3D + Prodigi |
| **OddHobbies** | Hobby accessories, game accessories, collector displays | Makr3D + Prodigi |
| **DivergentJoy** | Neurodivergent planners, sensory tools | Prodigi + self-fulfilled |
| **Grimoirer** | Occult tools, grimoire kits, tarot | Prodigi + Contrado + self-fulfilled |
| **PogPet** (Etsy) | Brick figures, cards, stickers | Prodigi + Makr3D |

## Supplier Categories

| Category | Suppliers | Products |
|----------|-----------|----------|
| **3D Print** | Makr3D, Shapeways alternatives | Physical 3D objects |
| **Flat Print** | Prodigi, Printseekers | Cards, stickers, prints, wrapping |
| **Apparel** | Printful, Gelato | T-shirts, mugs, home |
| **Premium** | Contrado, local artisans | Leather, luxury, custom |
| **Digital** | Self-fulfilled | Templates, apps, downloads |

## How to Use

Each store's `docs/SUPPLIERS.md` should reference this repo and duplicate only store-specific notes (e.g., which SKU to use, custom pricing).

Canonical supplier data lives here.
